# 工作台 - 在线版

这是一个可以在手机浏览器中访问的个人工作台应用。

## 功能特性

### 📊 总览
- 今日任务管理
- 本月收支统计
- 财务概览

### 🌿 生活
- **每日消费**：日历形式记录消费，点击查看每日明细
- **运动记录**：支持多种运动类型，记录时长和备注
- **月收入**：追踪收入来源和时间

### 🔥 外化（内容抓取）
- **抖音爆款**：展示热门视频内容
- **小红书爆款**：展示热门笔记
- **成分党笔记**：护肤成分分析内容

**自动刷新**：每6小时自动抓取更新内容

### 🎓 内化（学习训练）
- **雅思训练**：听力、口语、阅读、写作四个模块
- **阅读书架**：管理个人藏书，记录阅读进度

## 部署方式

### 方式一：本地部署（推荐）

1. 确保已安装 Node.js
2. 双击 `start.bat` 启动服务器
3. 获取电脑 IP 地址：
   - Windows: 打开命令提示符，输入 `ipconfig`，查看 IPv4 地址
4. 手机访问：
   - 确保手机和电脑在同一 WiFi
   - 在手机浏览器输入：`http://电脑IP:8080`
   - 例如：`http://192.168.1.100:8080`

### 方式二：使用 GitHub Pages（免费）

1. 创建 GitHub 仓库
2. 上传所有文件（index.html, manifest.json, sw.js, server.js）
3. 进入仓库 Settings → Pages
4. 选择 main 分支，点击 Save
5. 访问生成的链接即可使用

### 方式三：使用 Netlify（免费）

1. 注册 Netlify 账号
2. 拖拽整个文件夹到 Netlify
3. 自动生成访问链接

## 手机使用建议

### Chrome 浏览器
1. 访问网站后，点击三个点菜单
2. 选择"添加到主屏幕"
3. 像普通 App 一样使用

### Safari 浏览器 (iOS)
1. 访问网站后，点击底部分享按钮
2. 选择"添加到主屏幕"
3. 像普通 App 一样使用

## 技术说明

- **精确跳转**：使用抖音/小红书官方分享链接格式
- **自动刷新**：前端定时器每6小时检查更新
- **数据持久化**：使用 localStorage 存储本地数据
- **PWA 支持**：可离线使用，可添加到主屏幕

## 文件说明

- `index.html` - 主页面（所有功能）
- `manifest.json` - PWA 配置文件
- `sw.js` - 服务工作者（离线支持）
- `server.js` - Node.js 服务器
- `start.bat` - Windows 启动脚本

## 注意事项

1. 手机和电脑必须连接同一个 WiFi
2. 确保电脑防火墙允许 8080 端口
3. 建议关闭电脑的省电模式
4. 数据存储在浏览器本地，清除缓存会丢失
